# B站学习陪伴 · 使用说明

一个 Chrome / Edge 浏览器扩展：看 B 站网课时**自动记录**观看时长与课程进度，用打卡日历、连续天数和成就徽章激励自己坚持。

> 数据全部保存在你自己的浏览器本地，不上传、不需要登录、不发任何网络请求。

---

## 一、安装（一次性，约 1 分钟）

1. 打开 Chrome 或 Edge 浏览器，在地址栏输入：
   - Chrome：`chrome://extensions`
   - Edge：`edge://extensions`
2. 打开右上角的 **「开发者模式」** 开关。
3. 点击 **「加载已解压的扩展程序」**。
4. 选择本文件夹（包含 `manifest.json` 的这一层目录）。
5. 工具栏出现绿色播放图标 ✅ 安装完成。

> 只要不删除这个文件夹、不在浏览器里点「移除扩展」，它就会一直生效。浏览器重启也没关系。

---

## 二、怎么用

1. 在 B 站打开一个网课视频，正常播放即可 —— 进度会**自动记录**，无需任何操作。
2. 想看数据：点工具栏的绿色图标，弹出「快速看板」：
   - 今日观看时长、本周、本月
   - 🔥 连续打卡天数
   - 最近 4 周打卡热力图
   - 最近学习课程的完成进度
3. 点 **「查看完整统计 →」** 进入详情页：
   - 累计观看、连续/最长打卡、完成课程/课节数
   - 日 / 周 / 月切换的趋势图
   - 26 周打卡日历（GitHub 风格）
   - 每门课的完成度 + 分P方格（✓ 表示看完）
   - 成就徽章墙

---

## 三、统计规则（你关心的口径）

| 项目 | 规则 |
|---|---|
| 有效观看时长 | 按**真实时间**计。2 倍速看 30 分钟视频 = 记 15 分钟。暂停、缓冲、切到别的标签页都**不计时**。 |
| 拖动进度条 | 快进/快退**不计入时长**，也不会把跳到的位置算成"看过"，避免刷进度。 |
| 打卡 | 当天有效观看 ≥ 60 秒即算打卡一天（阈值可在 `lib/core.js` 里改）。 |
| 连续天数 | 今天还没看，不会立刻断签（从昨天算起）。 |
| 单节完成 | 看到 95% 以上或播放到结尾，标记为完成。 |
| 课程完成度 | 已完成分P数 ÷ 分P总数。 |

**徽章**：连续 7 天 🔥 / 单日 2 小时 ⏱️ / 看完一门课 🎓 / 累计 10 小时 🌊 / 看完 30 节 🧩

---

## 四、隐私与数据

- 数据存在浏览器的 `chrome.storage.local`，**只有你自己能看到**。
- 详情页底部有 **「清除全部数据」** 按钮，可随时彻底删除（不可恢复）。
- 扩展只申请了 B 站站点的读取权限和本地存储权限，不碰密码、Cookie、其他网站。

---

## 五、B 站改版后不记录了怎么办？

B 站偶尔会调整页面结构。采集主路径依赖视频元素本身（很稳定），一般不受影响；若标题/分P识别异常：

1. 打开视频页按 F12 → Console，过滤 `[BiliCompanion]` 看日志。
2. 大概率是选择器失效，只需改 **`lib/core.js`** 里的 `SELECTORS` 配置表（所有选择器都集中在这一个地方）。
3. 改完回到 `chrome://extensions` 点这个扩展的 **刷新** 按钮即可，数据不会丢。

## 六、文件结构

```
├── manifest.json          扩展配置
├── background.js          后台汇总、落库、判定打卡与徽章
├── lib/
│   ├── core.js            常量 + 选择器配置表（改版时改这里）+ 工具函数
│   ├── store.js           本地存储读写封装
│   └── stats.js           统计逻辑（日/周/月、连续天数、完成度、徽章）
├── content/
│   ├── detector.js        页面识别（bvid/分P/标题/视频元素）
│   ├── tracker.js         播放心跳与有效时长累计
│   └── content.js         注入入口
├── popup/                 工具栏快速看板
├── options/               完整统计详情页
└── icons/                 图标
```
